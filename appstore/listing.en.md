## Description (4000)

Most mobile terminals fall apart the moment you use an input method: half-composed text vanishes, characters get sent twice, wide characters drift out of line. tterminal was built with input methods as a first-class concern from day one.

TYPING THAT WORKS
Composition shows up right at the cursor and is only sent once you pick a candidate. Zhuyin, Cangjie, Pinyin, Japanese — they all behave. CJK filenames, commit messages and full-width punctuation line up the way they should.

THE TERMINAL BASICS, DONE PROPERLY
• Password or key authentication. The host fingerprint is pinned on first connect, and you're stopped if it ever changes
• htop, vim, tmux and less run as they should, GPU-rendered with smooth scrolling
• An extra key row above the keyboard: esc, ctrl, tab, arrows, plus one-tap ^C and ^D
• Long-press and drag on the terminal for an arrow-key joystick, handy in vim
• Adjustable font size

STEP AWAY, COME BACK
Switch out to answer a message and your session is usually still there. While you're away, the Dynamic Island and Lock Screen show how many connections are open. (iOS limits background time, so a long absence will still get the app suspended.)

ALL YOUR HOSTS IN ONE PLACE
Pin the ones you use most, search the rest by name, address or user.

SYNC THROUGH YOUR OWN SERVER
No account to create. To sync hosts and keys between your iPhone and iPad, run your own sync server — one docker command. Ideally on a NAS or small box at home, not exposed to the internet, reached over a VPN when you're out. Everything is encrypted on the device (XChaCha20-Poly1305) before it leaves, so the server only ever stores ciphertext. Not even I can read it. The server is open source under AGPL-3.0, so you can check for yourself.

GREAT ON BIG SCREENS
On iPad and an unfolded iPhone Duo you get two columns: connections on the left, terminal on the right. Half-fold the Duo and the layout follows the hinge.

TRY IT, THEN PAY ONCE
The download is free and every feature is unlocked for 14 days. If it works for you, unlock it with a single purchase that covers all future 1.x updates. No subscription, no ads, no tracking. If you don't buy, your hosts and sync stay put; you just can't open new connections.
